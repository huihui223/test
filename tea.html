中国茶 · 六大分类

一片树叶
六种滋味

绿、白、黄、青、红、黑——中国茶分为六大类，区分的依据不是茶树品种， 而是加工工艺，尤其是茶多酚的氧化程度（俗称「发酵」）。 从枝头到杯中，工艺的毫厘之差，造就了六种截然不同的风味。

绿茶

不发酵 · 0%

采摘后立即高温杀青，锁住鲜叶中的酶，使其不发生氧化。 清汤绿叶、滋味鲜爽，是中国产量最大、品类最丰富的茶类。

  • 工艺鲜叶 → 杀青（炒/蒸）→ 揉捻 → 干燥
  • 风味清香鲜爽，栗香或豆香，回甘明显，忌苦涩焖熟
  • 代表西湖龙井、碧螺春、黄山毛峰、信阳毛尖、六安瓜片
  • 冲泡80–85°C，玻璃杯或白瓷盖碗，不宜加盖久焖

白茶

微发酵 · 5–10%

工艺最自然的茶：不炒不揉，仅经萎凋与干燥，表面满披白毫。 新茶清甜毫香，陈年则药香枣香渐显，素有「一年茶、三年药、七年宝」之说。

  • 工艺鲜叶 → 日光/室内萎凋 → 干燥（不炒不揉）
  • 风味毫香蜜韵，汤色浅杏黄，入口清甜柔和
  • 代表白毫银针、白牡丹、贡眉、寿眉（主产福建福鼎、政和）
  • 冲泡90–95°C，盖碗；老白茶可煮饮

黄茶

轻发酵 · 10–20%

绿茶工艺之外多一道「闷黄」：杀青后以湿布或纸包裹轻发酵， 让叶绿素轻微分解。黄汤黄叶，鲜爽中添一份醇和，产量稀少。

  • 工艺鲜叶 → 杀青 → 揉捻 → 闷黄 → 干燥
  • 风味杏黄明亮，甜醇平和，少绿茶之寒而保有鲜爽
  • 代表君山银针、蒙顶黄芽、霍山黄芽、远安黄茶
  • 冲泡85°C 左右，玻璃杯可观「茶针三起三落」

青茶

半发酵 · 15–70%

即乌龙茶，工艺最繁复：叶缘经摇青碰撞而氧化红变，叶心仍保持青绿， 「绿叶红镶边」。发酵度跨度大，从清香铁观音到浓艳大红袍各具风骨。

  • 工艺鲜叶 → 晒青 → 摇青做青 → 炒青 → 揉捻包揉 → 烘焙
  • 风味花香果香馥郁，醇厚回甘、耐冲泡，「七泡有余香」
  • 代表铁观音、大红袍、武夷肉桂、凤凰单丛、冻顶乌龙、东方美人
  • 冲泡95–100°C 沸水，小盖碗或紫砂壶，快出汤、可多泡

红茶

全发酵 · 80–90%

不经杀青，直接萎凋揉捻后充分发酵，茶多酚氧化为茶黄素、茶红素。 红叶红汤、甜香温润，是世界上饮用最广的茶类，英文称 black tea。

  • 工艺鲜叶 → 萎凋 → 揉捻 → 发酵 → 干燥
  • 风味蜜糖香、花果香或松烟香，汤色红艳，口感温润甜醇
  • 代表祁门红茶、正山小种、金骏眉、滇红、宜红；印度阿萨姆/大吉岭
  • 冲泡90–95°C，白瓷盖碗或壶，可调奶、调糖

黑茶

后发酵 · 持续转化

杀青后经渥堆，借助微生物和湿热作用进行后发酵，且在存放中持续转化。 多紧压成砖、饼、沱，越陈越香，是边塞「茶马互市」的千年主角。

  • 工艺鲜叶 → 杀青 → 揉捻 → 渥堆 → 干燥 → 蒸压成型
  • 风味陈香、木香、枣香或菌香，汤色褐红透亮，滋味醇厚顺滑
  • 代表熟普洱茶、安化茯砖（金花）、广西六堡茶、湖北青砖、四川藏茶
  • 冲泡100°C 沸水，紫砂壶为佳，冲泡前先洗茶一遍

存茶与选购

茶叶是有生命力的食物，保存得当才能常饮常新

藏如何存放

避光 · 密封 · 干燥 · 无异味，是存茶的四要素。

绿茶、黄茶、清香型乌龙怕氧化受潮，宜冷藏（密封后放入冰箱冷藏层，取出后等回温再开封）。

红茶、白茶、普洱、黑茶则喜通风阴凉、干爽无杂味，其中普洱与老白茶在合适湿度下可长期陈化，越存越醇。

辨如何看干茶

好干茶三看：色泽润、条索整、香气纯。

润——表面有自然光泽而非枯灰暗；整——条索匀整碎末少；纯——凑近闻无青草气、陈霉味或烟焦味。

绿茶翠润、红茶乌润、白茶银白满披、黑茶褐润有光泽，各有其该有的样子。

选如何按口味选

怕苦怕涩、喜欢清鲜 → 选绿茶、黄茶、白牡丹。

喜欢香高味醇、有层次感 → 选乌龙（铁观音、大红袍、单丛）。

喜欢温润甜醇、接受度高 → 选红茶（祁红、正山小种、滇红）。

喜欢陈香厚重、可长期存放 → 选熟普、老白茶、六堡等黑茶。
